# Nzietelo — Groupe 2 (Aki-Tech)
Akieni Academy — Évaluation S8

Le projet vise à créer une solution de covoiturage inter-quartiers pour fluidifier les trajets quotidiens, partager les frais et renforcer la fiabilité, en s'attaquant non seulement au coût mais aussi à la disponibilité, au temps perdu, aux détours et à la confiance envers les inconnus.

## I.Comment installer
**1.Cloner le dépôt**
```bash
git clone https://github.com/Cyrille-WiseCode/s8-akitech-nzietelo.git
```
**2.Lancer le projet**
```bash
cd backend
pip install -r requirements.txt
python app.py
```
Ouvrir le fichier index.html dans le dossier accueil avec live server si on est sur vs code.
## II.Comment utiliser
Une fois sur la landing page,
- **Créer un compte en cliquant sur s'inscrire si nouvel utilisateur :** renseigner le nom, le téléphone et le mot de passe puis cliquer **créer mon compte**;
- **Se connecter en cliquant sur se connecter si ancien utilisateur :** renseigner le téléphone et le mot de passe puis cliquer sur **se connecter**
- **Rechercher les trajets disponibles :**

  rechercher un trajet en entrant le quartier dans la barre de 	recherche ou en sélectionnant le quartier dans la liste joint dans 	la barre de recherche.
  Ensuite, cliquer sur le bouton voir le trajet afin de consulter les 	détails du trajet sélectionné;
- **Réserver une place :**

  Une fois sur la page détails du trajet sélectionné, réserver une place en renseignant le nom et le téléphone puis cliquer sur le 	bouton **réserver une place**.
  Après avoir réserver, un message de confirmation apparaît si toutes les informations ont été correctement renseignées.
  L'utilisateur passe alors aux prochaines 	étapes : **retour à l'accueil**, **voir mes trajets** ou **rechercher d'autres trajets**.
  Si non, un message d'erreur apparaît et l'utilisateur reprend le 	processus de réservation.
- **Voir mes trajets :** consulter les trajets réservés en renseignant le téléphone puis cliquer sur le bouton voir mes trajets.
- **Consulter le dashboard :**

  Vérifier toutes les statistiques de l'application en consultant **les trajets disponibles**, **le nombre de conducteurs actifs**, **les réservations actives**, **la note moyenne des   conducteurs**, **le taux d'annulation**, **le top 3 des conducteurs**, **le trajet vedette**, **la répartition par quartier de départ (quartier, 	nombre de trajets, prix moyen)**.
